# سیستم احراز هویت و دسترسی

## نقش‌ها (۴ سطح)

| نقش | ساخته می‌شود با | ورود |
|---|---|---|
| `super_admin` مدیر ارشد | seeder (`SUPER_ADMIN_*` در `.env`) | موبایل + رمز + **OTP اجباری** |
| `admin` مدیر | فقط توسط super_admin (`/admin/admins`) | موبایل + رمز + **OTP اجباری** |
| `expert` کارشناس | ثبت‌نام عمومی (`/register`) | موبایل + رمز |
| `greenhouse_owner` گلخانه‌دار | ثبت‌نام عمومی (`/register`) | موبایل + رمز |

مقادیر نقش‌ها در `App\Enums\Role` است (برچسب فارسی، نیاز به OTP، قابل‌ثبت‌نام‌بودن).
سطح دسترسی بیشتر از نقش (مثلاً مالکیت پرونده) باید با Policy پیاده شود؛ `super_admin` از `Gate::before` عبور می‌کند.

## جریان‌ها

- **ثبت‌نام** `/register`: انتخاب نقش، فرم مخصوص هر نقش → کاربر `pending` ساخته می‌شود → OTP → `/verify-mobile` → فعال و واردشده.
- **حساب ساخته‌شده توسط مدیر ارشد** (بدون رمز): `/activate` ← شماره → OTP → تعیین رمز → ورود (با OTP دومرحله‌ای).
- **ورود** `/login`: اگر موبایل تأیید نشده باشد به `/verify-mobile` می‌رود؛ برای admin/super_admin بعد از رمز به `/two-factor` می‌رود و **تا تأیید کد وارد نشده است**.
- **فراموشی رمز** `/forgot-password` ← OTP ← `/reset-password`. بعد از تغییر رمز، همه‌ی سشن‌های قبلی (درایور `database`) حذف می‌شوند و کاربر **خودکار وارد نمی‌شود**.

## ویژگی‌های امنیتی (که تست دارند)

- مرحله‌ی «تعیین/تغییر رمز» فقط با علامت سمت‌سرور `OtpService::consumeVerified()` در سشن اجرا می‌شود؛ پراپرتی‌های Livewire حساس `#[Locked]` هستند.
- کد OTP فقط به‌صورت HMAC ذخیره می‌شود؛ ۵ تلاش، انقضای ۲ دقیقه، یک‌بارمصرف، وابسته به هدف (کد بازیابی رمز برای ورود کار نمی‌کند).
- محدودیت: ۶۰ ثانیه بین ارسال‌ها، ۸ پیامک/ساعت برای هر شماره، ۳۰ پیامک/ساعت برای هر IP.
- ورود: ۵ تلاش ناموفق/دقیقه برای هر (شماره+IP) و ۲۰/ساعت برای هر شماره؛ پیام خطای یکسان برای «شماره نامعتبر» و «رمز اشتباه».
- حساب غیرفعال‌شده در درخواست بعدی خودکار خارج می‌شود (`active` middleware).

## پیامک

`App\Services\Sms\SmsGateway` یک interface است و فعلاً فقط `LogSmsGateway` وجود دارد (کد در `storage/logs/laravel.log`، فقط در `local`/`testing`).
برای افزودن sms.ir: کلاس `SmsIrGateway` بسازید که `sendOtp()` را پیاده کند، سپس در `AppServiceProvider::register()` یک شاخه‌ی `'smsir'` به `match` اضافه کنید و `SMS_DRIVER=smsir` بگذارید (کلیدها در `config/sms.php` رزرو شده‌اند).

## راه‌اندازی محلی

```bash
cp .env.example .env            # SUPER_ADMIN_MOBILE / SUPER_ADMIN_PASSWORD را پر کنید
php artisan key:generate
php artisan migrate:fresh --seed
composer test
```

> مایگریشن `users` بازنویسی شده است؛ روی دیتابیس‌های قدیمی `migrate:fresh` لازم است.
> کاربران دمو (فقط `local`): `09120000001` مدیر، `09121111111` کارشناس، `09123333333` گلخانه‌دار، رمز `Password1`.

## افزودن منوی جدید

آیتم را به `config/navigation.php` اضافه کنید (`roles => null` یعنی همه‌ی نقش‌ها). آیتم فقط وقتی دیده می‌شود که route وجود داشته باشد.
